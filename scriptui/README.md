# Motion Graphics · JSX 1.8.0

AE 2023 原生脚本面板。只需一个 MotionGraphics.jsx 文件，不依赖 CEP、外部素材、网络或注册表。本版精简界面，保留动画和工具引擎。

## 运行与安装

直接试用：关闭旧面板，在 AE 中选择“文件 > 脚本 > 运行脚本文件…”，打开新版 MotionGraphics.jsx。不要在 Windows 中双击脚本。

停靠使用：复制文件到 AE 安装目录的 Support Files\Scripts\ScriptUI Panels\，重启 AE 后从“窗口”菜单打开。本机路径：

    D:\Software\AE2023\Adobe After Effects 2023\Support Files\Scripts\ScriptUI Panels\MotionGraphics.jsx

不需要复制到 CEP 目录或开启开发模式。本次交付没有自动安装或修改系统设置。

## 精简后的操作

1. 在“UI 动效 / 效率工具”切换，用下拉菜单选分类。
2. 选中图层，单击对应预设立即应用；没有额外的“应用到选中图层”按钮。
3. 在图层“效果控件”的 MG 控件中调整距离、方向、幅度、角度、弹性、次数、循环周期等。参数修改立即参与计算，不需要回面板更新。
4. 起点、终点和时长仍通过原图层的范围标记调整。直接拖动/拉伸，也可使用 AE 自带的标记对话框。
5. 删除某个范围标记，移除对应动效。

入场动画现在有 36 项，出场动画有 34 项。面板每页显示 8 项，通过分类栏右侧的上一页/下一页按钮切换，避免面板因按钮过多而变高。

已移除参数区、读取/重置参数按钮、“应用到选中图层”、“结果详情”、“当前图层”选项卡及其查看/定位/范围编辑界面。底部保留简短操作和错误提示，悬停可查看完整提示。建议面板约 400 × 490 像素。

不影响已有动画计算、效果控件调参、范围标记控时、删除联动、图层错帧/循环/绑定等核心功能。变化是不能在应用前从面板修改动效参数，也不再由面板列出当前图层的全部效果或定位起止；这些工作改在 AE 效果控件和时间线完成。

## 动画参数与重复点击

- 新添加的动效使用预设默认值，再在效果控件中调整。
- 重复单击图层上同一个已有动效，不重置参数、参数关键帧或范围。多选时按每个图层独立判断；没有该动效的图层正常添加。
- 更换同类预设会使用新预设默认值，保留已有范围。带动画的共享控制器仍会触发原来的保护提示。
- 不同类别可叠加。循环总范围由标记决定，单次周期在效果控件调整；范围结束后保持末态，不自动回原位。
- 标记控时开启时，旧“时长 秒 / 偏移 秒”滑块为兼容工程保留，不决定范围，请调整标记。距离等其他属性继续使用效果控件。
- 顶部“标记控时”默认开启。关闭只影响新动效，改由效果控件的时长和偏移控制，不创建标记；已有动效不会切换模式。
- 默认入场从入点开始、出场在出点前结束、反馈从播放头开始。**新循环动画从当前时间指示器开始，范围时长固定为 1 秒**，即结束点在播放头后 1 秒。范围不裁切原图层入点或出点。

## 效率工具的必要设置

错帧间隔和随机种子是执行工具时的输入，不是图层效果属性，因此仅在“错帧排列”分类保留一行小输入框。先输入间隔再单击顺序、反向或随机错帧；随机种子仅用于随机错帧。其他分类不显示这些输入框。

“移除关键帧循环”保留在对应分类，因为它不使用 UI 动效范围标记。其他工具沿用 AE 撤销操作。

图层循环提供“图层重复”和“图层往返”。往返模式按当前裁切片段从首帧播放到最后一个可见帧，下一帧立即反向，避免采样图层出点的空白帧；片段至少需要两帧。已经由本插件循环的图层可以直接点击另一种模式切换，保留原裁切范围；第三方时间重映射不会被覆盖。

## 范围标记和删除联动

- 范围标记直接放在原图层，不创建新控制层；移动和复制原图层会携带标记，副本独立。
- 范围可重叠，但起点不能完全相同。面板创建时遇到占用会整体顺延到空闲帧并保留时长。顺延会改变实际动画时间，终点也一起顺延。
- 手动拖动没有自动避让。覆盖其他标记也视为删除，误操作请按 AE 历史顺序撤销。
- 删除标记后对应动效立即停止，关闭面板时也有效。其他类别动效、用户标记、用户效果和原始关键帧保留。
- 面板显示且对应合成为活动合成时，空闲约 1–2 秒后清理对应控件、表达式和记录。面板关闭/隐藏或渲染期间不执行清理。
- **自动清理单独占一次撤销。** 清理完成后通常需要先撤销清理，再撤销标记删除；中间有其他编辑时按实际历史顺序恢复。撤销清理后不会再次自动清理，标记恢复后动效恢复。
- 零时长、重复内部 ID 按异常范围处理，不自动删除。不要修改标记内部参数。
- 关闭面板后动画仍按效果控件及标记计算。面板定时任务只负责已删除标记的控件清理，不依赖被移除的“当前图层”界面。

## 旧工程升级与异常范围修复

旧工程不会因打开新版而自动改动。选择需处理的图层，打开“帮助 → 旧动效升级/修复”：

- 旧参数动效转换为原图层范围；动态时间参数或外部表达式异常会阻止转换。
- 1.2.0 原图层范围保留有效时间并启用删除联动。
- 1.1.0 控制层动效迁回原图层，保留已编辑范围。共用或有用户内容的旧控制层保留，无其他用途的控制层清理。
- 1.3.0 已有效的范围无须升级。零时长或重复 ID 的范围可按保存值修复。
- 已按删除联动删除的范围不会被升级操作重新创建，须用 AE 撤销恢复。
- 支持选中多个图层，逐项升级并保留选择。锁定、损坏元数据及第三方表达式会保护并提示。

重复点击同一个旧动效也不会悄悄升级或重置参数，升级请使用上述帮助入口。

## 保护与限制

UI 动效支持 2D 文字、形状、图片、视频和预合成，不支持摄像机、灯光、空对象及 3D。图层循环仅支持视频和预合成。原注释、手工标记、关键帧及第三方表达式沿用原有保护。

外部表达式若通过 marker 序号取值，新增标记可能改变它们的序号。可关闭“标记控时”让新动效使用参数控时。

此版不含动态图标、自定义预设存储、锚点定位及独立缓动工具。保留 CEP 源码供后续开发，不将此版安装到 CEP。

## 从参考工程转换的预设

已读取 `入场动画.aep` 中全部 31 个同名合成及其 `TARGET` 图层：波浪弹跳、弹弓、弹簧、弹入跳动、掉落弹跳、抖动甩入、二段缩放、翻动、放大震动、汇聚、卡片、空翻、碰碰车、生长2、甩出、跳跳糖、跳跃、吸入、向上弹入、向上翻转、向右缓入、向右模糊2、向左模糊、旋入、旋转、旋转缩放、雪光模糊、右上弹入、砸落、左上弹入、左移弹动。

已读取 `出场动画.aep` 中全部 29 个同名合成及其 `TARGET` 图层：边角缩放、波浪弹出、波浪弹跳、弹出、二段缩放、放大、飞出、渐隐、拉伸模糊、螺旋下降、模糊发光、闪现、收缩震动、甩回、缩小、躺下、向上飞出、向上滑动、向下弹出、向下翻转、向右滑动、向左模糊、消散、虚影放大、旋出、旋转、折叠、左上弹出、左移弹动。出场范围结束后保持参考工程的最终离场姿态；删除范围则立即恢复图层原状态。

“消散”的 CC Page Turn 动画额外提供 `MG / OUT 23 / Fold Start` 和 `MG / OUT 23 / Fold End` 两个点控件。它们位于图层效果控件中，可分别修改 Fold Position 轨迹的起点和终点；范围标记仍控制整体速度。重复应用保留这两个点，替换出场预设或删除出场范围时随该预设一起清理。若图层已使用 1.7.0 的“消散”，安装新版后再点击一次“消散”即可补齐控件并升级表达式。

关键帧及源表达式中的弹跳、衰减和抖动被转换为相对运动，以应用图层现有位置、缩放、旋转和透明度为最终状态。范围标记控制整体时长，拖长或缩短范围会整体重定时。

对应预设会自动创建 CC Force Motion Blur、CC Slant、CC Page Turn、湍流置换、径向模糊、波形变形、极坐标、发光或高斯模糊。动态效果参数跟随范围，静态参数可在效果控件直接调整。插件效果使用 `MG / IN 编号 / 效果名` 或 `MG / OUT 编号 / 效果名` 的短名称，以兼容 AE 的效果名称长度限制；重复点击保留调整，替换同类预设或删除范围标记时只移除对应类别拥有的实例，用户自行添加的同类效果不受影响。入场和出场即使使用同一种效果，也分别管理，不共享参数或删除关系；范围重叠时 AE 会按效果栈正常叠加。
