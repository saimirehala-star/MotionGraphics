
## Motion Graphics 功能

- **AI 助手**：通过本机 Codex App Server 对话操作 AE，支持独立编辑和调用已有插件功能。
- **UI 动效**：80 个内置动效、团队 JSON 动效预设、范围标记与分类清除。
- **效率工具**：15 个工具操作和团队表达式库，新增合成提取、脱钩复制、标记提取。
- **预渲染**：独立的顶层时间块缓存工作区。
- **模版**：把当前合成保存为带分类、预览和资源的团队 `.aep` 模版包；单击卡片即可导入当前工程。
- **素材库：**可创建文件分类，导入常用格式。

## 安装

1. 关闭 AE 2023 并完整解压 ZIP。
2. 在解压目录运行 `./install.ps1 -EnableDevelopmentMode`。
3. 然后重启 AE。
4. 打开“窗口 > 扩展 > Motion Graphics · Team Templates”。（确保AE已经勾选“允许脚本写入文件和访问网络”）

也可以把 ZIP 内完整的 `MotionGraphicsUserPresets` 文件夹复制到 `%APPDATA%\Adobe\CEP\extensions\`。最终应存在 `%APPDATA%\Adobe\CEP\extensions\MotionGraphicsUserPresets\CSXS\manifest.xml`。这是未签名开发版，需要为当前用户启用 CEP 11 的 `PlayerDebugMode`。

安装脚本遇到同名安装目录时会先备份到 `%APPDATA%\MotionGraphics\backups`，不会覆盖本工作区中的历史版本源码。

## AI 助手

AI 助手只通过本机 Codex App Server 工作，复用当前 Codex 配置和 CC Switch 的 provider、模型、代理、重试及认证设置。
使用时先点击“连接 Codex”。如果当前 provider 已配置，面板会直接显示已配置状态；否则点击“登录 ChatGPT”完成官方登录。

**AI 首次使用**
1. 安装并重启 AE，打开“AI 助手”。不捆绑 Codex 可执行程序；已有 Codex 桌面版时会尝试自动查找，也可以填写 `codex.exe` 的绝对路径。仅支持实际可执行文件，不接受 `.cmd` 或整段命令。
2. 单击“连接 Codex”，再单击“登录 ChatGPT”，在官方浏览器页面完成登录。插件使用独立 Codex 配置，因此即使桌面版已经登录，这里首次仍需登录。
3. 选择模型，打开目标合成，选中需要修改的图层后发送需求。空工程也可以要求新建合成。账号必须具备相应模型访问权限；列表出现模型不代表账号一定能调用，失败时不会静默换模型。
4. 如果使用 CC Switch / ApiNebula 等 provider，请先在 Codex 或 CC Switch 中完成配置，插件会直接复用该配置。

本机使用 Codex CLI `0.153.4` 完成了协议握手、模型列表读取和动态工具注册。该动态工具接口仍是实验接口，后续 Codex 升级可能需要适配。本版还未完成登录后的真实模型端到端对话验收，请先在测试工程中使用。

独立操作支持新建合成、文字、形状、空对象、纯色层，修改父子关系、时间范围、属性、关键帧、表达式和添加已安装的 AE 效果。插件调用支持动效、图层工具、导入已有模版以及预渲染相关操作。后台保存模版仍从模版页面操作，本版没有将该异步流程开放给 AI。

超出结构化工具能力时，可以主动开启“允许自由 JSX”。每次会显示脚本和用途，确认后执行。自由 JSX 不是安全沙箱，能力覆盖 AE 脚本及其可访问的文件；不要执行无法判断用途的脚本。本版没有截图、鼠标或逐帧视觉验证工具，不能等同于 Codex 桌面版的全部能力。

**AI 数据、确认和性能**

- 发送时读取当前合成、图层名称、选中对象、效果清单；按需读取属性、关键帧、表达式和团队库。相关文字会发送给所选模型服务，不自动上传原素材文件。工程文字按数据处理，不能作为额外指令。
- 上下文最多列出 200 个图层，属性树最多 300 个节点，团队库每次最多返回 100 条摘要；表达式代码需指定条目读取。大型共享库的目录扫描仍可能耗时。
- 登录由官方 Codex 管理，插件不复制桌面版认证文件、不把密钥写入 localStorage 或共享盘。独立配置位于 `%APPDATA%\MotionGraphics\AI`，使用 Codex `auto` 凭据存储策略；系统凭据存储不可用时可能回退为本地文件，应保护本机账号。
- 本版对话使用临时线程；聊天记录由插件本地保存，可在“历史会话”中打开或删除；服务端数据处理仍受所用服务政策约束。
- 删除、清除关键帧、表达式变更、渲染等操作需确认，也可以勾选“每次修改前确认”。模型拒绝或工具出错会显示在对话里。
- 任务锁定工程和目标合成，切换合成后拒绝继续修改。执行时请不要手动改动工程；项目内其他手动改动并非全部能检测。
- 每批结构化修改放在一个 AE 撤销组中。失败可能保留部分修改，检查结果后可在 AE 撤销。文件写入和渲染产物不保证可以撤销。
- “停止”阻止后续步骤、取消尚未送入 AE 的 AI 操作；已经执行的 AE 脚本或渲染不能保证立即中断。
- 未连接时不启动 AI 进程；连接后本机 Codex 保持运行，退出面板会关闭插件自己启动的进程。AI 不增加定时扫描 AE 的循环。

协议与登录说明：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[Codex Authentication](https://learn.chatgpt.com/docs/auth)。

## UI动效

内置 80 个动效预设，涵盖入场、循环、出场和交互反馈。选中 AE 图层后，单击预设卡片即可应用，支持名称搜索和动态预览。

可使用预设默认时长，也可在应用前自定义时长；应用后，在图层的效果控件中调整参数。动效范围通过图层标记显示，方便查看和调整，并支持一键清除对应分类的动效。

支持将图层上的关键帧、表达式及效果保存为自定义 JSON 预设，并设置共享存储目录，方便团队复用。

## 效率工具

提供常用图层与合成操作，减少重复工作：
- **错帧排列**：按顺序、反向或随机错开图层时间，支持设置间隔帧数。
- **关键帧循环**：支持重复、往返和偏移循环。
- **图层循环**：支持图层片段重复与往返播放。
- **空对象绑定**：将多个图层绑定到同一空对象，或分别创建空对象。
- **图层对齐**：统一多个图层的起点或入点。
- **合成操作**：提取子合成内部图层、脱钩复制嵌套合成、提取合成标记。
- **表达式库**：保存、搜索、编辑和删除常用表达式，查看使用说明并一键复制。

## 预渲染

将合成中的图层或动画片段渲染为本地缓存素材，减少复杂效果和重复计算带来的预览负担。
支持按时间块组织渲染任务，设置输出目录与输出模块，并将渲染结果用于当前工程。适合对已完成、短期内无需修改的动画进行预渲染，提高后续合成与预览效率。
原始内容修改后，需要重新渲染以更新缓存。

## 模版

将当前合成保存为独立的 `.aep` 模板，自动收集所需素材，并剔除无关的工程资源，方便在其他项目中复用。

保存时可自定义名称，选择已有分类或新建分类。模板卡片支持静帧预览、名称搜索和分类查看；单击卡片即可导入当前工程，并添加到当前合成。

支持自定义存储目录，方便团队共享。字体和外部插件不随模板收集，使用时需自行安装；高版本 AE 制作的模板建议在相同或更高版本中使用。

保存步骤：
1. 保存当前 AE 工程，并打开准备做成模版的合成。
2. 进入“模版”，单击顶部“保存当前合成”。
3. 输入名称，选择已有分类或新建分类，并填写可选说明。
4. 保存后可继续编辑当前工程；面板会显示后台任务进度。

后台实例通过 `AfterFX.com -noui -m -r` 运行，只打开当前工程的本机临时副本。CEP 面板使用非阻塞的短轮询等待窗口监控器就绪，不调用 CEP 主线程不支持的 `Atomics.wait`。窗口监控器只跟踪本次任务的准确 AE 进程；已有 AE 窗口不会被隐藏。若 AE 异常弹出需要人工处理的对话框，可单击任务条中的“显示后台 AE”。监控器只在模板任务期间运行，不修改系统 PowerShell 策略。

每个模版使用独立目录，包含精简后的 `template.aep`、`Resources`、`preview.png`、`manifest.json` 和 `ready`。插件会保留当前合成、嵌套合成、实际使用的文件与图片序列、启用的代理，以及表达式中以固定字符串写出的 `comp("名称")` 和 `footage("名称")` 依赖；无关项目项会被剔除。

素材按真实文件路径去重。分层 PSD/AI 的 AE 图层关系通过 AEPX 路径更新保留，不会把各子图层替换成完整源文件。图片序列按同目录、同前缀、同位数和同扩展名收集。字体和第三方插件不打包；动态拼接名称的表达式依赖无法可靠识别，缺失素材会保留为 AE 占位状态。

静帧首先使用当前时间头。若该帧完全透明，插件会检查活动图层范围、工作区和合成中段等候选时间，选择有画面的帧；如果整段都没有可见画面，卡片显示默认图标，不保存透明占位 PNG。合成的内部零基准时间和界面显示时间分别记录，支持非零显示起始时间。卡片视觉上居中裁切预览，但模版目录中的原始 PNG 保持完整比例。

在新工程中打开目标合成，将时间头放到需要的位置，再单击模版卡片。插件会导入 `.aep` 并把主合成作为预合成图层放到时间头。再次单击同一模版会复用已导入的主合成，避免重复导入整套项目项。

## 素材库

集中管理图片、视频和序列帧素材，支持自定义名称、创建分类、移动分组及名称搜索。素材封面完整显示原图，动态素材可在鼠标悬停时自动播放预览。

支持 PNG、JPG、GIF、SVG、PSD、TIFF 等图片，以及 MP4、MOV、AVI、MKV、WMV 等视频格式；实际导入能力取决于 AE 和素材编码。支持序列帧导入，并设置序列帧率。

点击素材卡片的添加按钮，即可将素材加入当前合成。存储目录可更改，方便个人整理和团队共享。
